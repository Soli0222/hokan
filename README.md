# hokan — 資産管理台帳

個人の物品・資産を台帳として管理するための Web アプリケーションです。

持ち物の取得日・取得価格・現在の見込み売却額を記録し、保有コストや「眠り資産」を把握できます。
棚卸しモードで定期的に現物を確認し、売却候補の優先順位付けも行えます。

## 主な機能

| 機能 | 概要 |
|------|------|
| **物品台帳** | 物品名・カテゴリ・取得日・取得価格・保管場所などを登録。名前の部分一致検索、カテゴリ・status・necessity_tier で絞り込み |
| **評価履歴** | 物品ごとに見込み売却額・流動性・根拠を履歴として記録。最新評価が現在の想定売却額になる |
| **処分記録** | 売却・下取り・廃り・廃棄・譲渡・寄付・紛失を記録し、物品を status=disposed にする。処分の修正と取消も可能 |
| **ダッシュボード** | 保有中合計（取得価格・見込み額）、眠り資産（dormant）、カテゴリ別集計、180日超過の未確認物品数を表示 |
| **棚卸し** | lastConfirmedOn が古い順（未確認が先頭）に物品を並べ、「確認した / 手放した / 編集 / スキップ」で巡回。残り N / 全 M の進捗表示 |
| **売却候補** | 不足額を指定すると necessity_tier が sub/dormant の物品を見込み額の高い順に選定し、合計額と除外件数を返す |
| **実質コスト・回収率** | 実質コスト（取得価格−売却・見込み額）、月あたりコスト、回収率を物品ごとに算出 |
| **データ管理** | 全データの JSON エクスポートと全置換インポート |
| **MCP** | backend 内蔵の `/mcp` から、AI クライアントで台帳を参照・更新 |

## 運用上の注意

- 金額は円の整数で管理します。
- `quantity > 1` の物品は**一部だけの処分を許しません**。一部だけ手放す場合は、先にレコードを数量ごとに分割してください。
- 棚卸しセッションのエンティティはありません。「残り N / 全 M」の M は棚卸し画面を開いた時点の件数で、画面内のメモリに保持します。

## 開発

- React の SPA と Hono の API を pnpm workspace で管理し、Prisma を通じて PostgreSQL に保存します。
- MCP は backend の `/mcp` に内包しています。
- 利用するバージョンは各 `package.json`、lockfile、コンテナ定義を参照してください。

テストは Makefile 経由で実行します（`make test-unit` / `make test-integration` / `make test-e2e` / `make lint` / `make typecheck` / `make build`）。

## デプロイ

- [Helm chart](charts/hokan/README.md)：Kubernetes への配置と values（ingress ホストは hokan.pstr.space）
- デプロイ設定・DNS・Keycloak クライアントの実登録は pke リポジトリで管理します。
